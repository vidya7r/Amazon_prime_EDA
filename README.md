# Amazon Prime Video - Exploratory Data Analysis (EDA)

This project performs an Exploratory Data Analysis (EDA) on Amazon Prime Video content data to uncover key insights into show characteristics, trends, and viewer ratings.

## File
- `Amazon Prime EDA.ipynb`: A Jupyter Notebook containing data cleaning, manipulation, visualizations, and key insights using Python libraries like Pandas, Seaborn, and Matplotlib.

## Objectives
- Understand the distribution of content by year, genre, runtime, and IMDb ratings.
- Identify the top-rated shows and their characteristics.
- Visualize relationships between numerical variables.
- Assist business stakeholders in making informed decisions based on content performance.

## Key Insights
- IMDb scores are moderately positively correlated with runtime.
- Most titles are short-form, with a few outliers having long runtimes.
- Drama and Comedy are the most dominant genres.
- Shows released between 2010–2020 represent the bulk of content.
- Boxplots and heatmaps highlight variation across content types and scores.

## Visualizations Included
- Histogram of IMDb ratings
- Boxplot of runtime by content type
- Pair plot of key numerical variables
- Correlation heatmap
- Count of titles released per year

## Conclusion
This analysis provides a data-driven foundation for content strategy on streaming platforms. By understanding viewer preferences, runtimes, and genres that drive high ratings, Amazon Prime can improve its content curation and recommendation systems.
